# Tips for Contributing

This page contains useful information for contributing to `open-dis-rust`, whether that
be as a bug reporter, a feature suggester, or a developer.

## GitHub

`open-dis-rust` is open-source, and the code is hosted on [Github](https://github.com/crhowell3/open-dis-rust).
There, you can create tickets for bug requests, documentation changes, or feature suggestions. You may
also submit pull requests. Your code will be reviewed, and if it passes review and the pipeline, it will
get merged in and eventually published in a new release.
