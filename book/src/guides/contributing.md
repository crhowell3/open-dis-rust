# Tips for Contributing

This page contains useful information for contributing to `open-dis-rust`, whether that
be as a bug reporter, a feature suggester, or a developer.

## GitHub

`open-dis-rust` is open-source, and the code is hosted on [Github](https://github.com/crhowell3/open-dis-rust).
There, you can create tickets for bug requests, documentation changes, or feature suggestions. You may
also submit pull requests. Your code will be reviewed, and if it passes review and the pipeline, it will
get merged in and eventually published in a new release.

## Development

`open-dis-rust` leverages the `2024` edition of Rust on the `stable` toolchain.

### Macro Expansions

This project uses Rust macros quite heavily to cut back on redundant code. The definitions for the
PDUs became pretty repetitive, so, in an effort to reduce points of failure, a very large portion
of that code was converted into macros, meaning that a sizeable amount of the code in this crate
is autogenerated. That's great for reducing the size of the codebase, but it quickly becomes a
nightmare if something breaks. There's a really convenient utility that alleviates this problem:

```shell
cargo install cargo-expand
cargo expand path::to::module
```
